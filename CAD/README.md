# CAD files

CAD and print files for the test rig and calibration board described in Chapter 4 of the report.

| Folder | Contents |
|---|---|
| `Rail/` | The sliding rail: 20x20 aluminium extrusion, carriage, V-wheels, feet, frame mounts and joiners. 3D print files are in `Rail/Printing/`. |
| `Board/` | The calibration board: `aprilgrid_36h11_10x7.pdf` is the AprilGrid image (10 x 7 AprilTag 36h11 tags, 35.36 mm tags, 10.61 mm gaps), printed on aluminium Dibond. 3D print files for the board's adjustable mount and protractor are in `Board/Printing/`. |
| `MountSteps/` | STEP files for the mount assembly. |
| `2020 Aluminium Profile variable angle bracket T-nut - 2942892/` | Variable angle bracket used for the board mount. |
