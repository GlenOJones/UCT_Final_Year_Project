\subsubsection{Calibraion analysis metrics}
Optimising for calibration requires careful consideration to avoid degrading the quality and coverage
of the calibration. Selectivly choosing frames to reduce RMS error results in losing what might be better 
calibration coverage. The harder to detect tags may increase RMS errors due to higher noise with their 
detections, resulting in worse RMS error therefore punishing the algortihms for an improved output.
To avoid this, four metrics are used to evaluate the calibration's algorithm's effectiveness:
\begin{enumerate}
    \item \textbf{Tag detection rate:} number of AprilTags detected, as a fraction of the total board tags.
    \item \textbf{Mean per-image RMS:} reprojection error computed separately for each image, then averaged over all images.
    \item \textbf{Overall RMS:} reprojection error over all detected corners, as returned by \texttt{calibrateCameraExtended}.
    \item \textbf{Parameter uncertainty:} standard deviations of the intrinsic parameters, as returned by \texttt{calibrateCameraExtended}.
    \item \textbf{Measurement accuracy:} error in tag size measured by stereo triangulation of a separate AprilTag target at distances of 50--250\,cm.
    \item \textbf{Matched-tag RMS:} reprojection error computed only over tags detected in all of the compared calibrations.
\end{enumerate}

\subsubsection{Tuning OpenCV detector parameters}

% OpenCV parameter adjustments, what, why, ,how (educated guess, followed by paramtere sweep), improved detection results
% CLAUDE ADAPTED TO THIS:
The next step was to tune the parameters of OpenCV's ArUco marker detector. To do this, a parameter sweep was run using \texttt{sweep\_detector.py} to find the configuration that detects the most
AprilGrid tags within accuracay metrics. Thirteen \texttt{DetectorParameters} were varied, covering thresholding, contour
filtering and the decoding of each tag's bits. Any configuration producing more than 0.5\% false identifications or duplicate tag detections was rejected.
